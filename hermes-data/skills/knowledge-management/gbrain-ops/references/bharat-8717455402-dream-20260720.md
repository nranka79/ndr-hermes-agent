### 2. Creating empty brain dir unblocks dream on Postgres brains

When `--dir` path doesn't exist but `HOME` points to a Postgres config, simply `mkdir` the target dir and re-run. The sync phase will fail (not a git repo) but all DB-backed phases (extract_facts, propose_takes, consolidate, grade_takes, embed, orphans, recompute_emotional_weight, etc.) run against Postgres. No content loss — the Postgres engine is the source of truth for DB phases.
