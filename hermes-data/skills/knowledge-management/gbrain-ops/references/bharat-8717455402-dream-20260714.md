## Key learnings

1. **The literal cron command is broken on two axes, not one.** Even if
   the `gbrain` binary were on PATH, the `--dir` path
   `/data/hermes/users/[REDACTED-TID]/brain` doesn't exist. The fix is
   twofold: (a) replace `gbrain` with `bun run /opt/gbrain/src/cli.ts`,
   (b) either use the DRAAS account path `sales1.blr` for `--dir`, or
   omit `--dir` entirely and accept the `no_brain_dir` skips for
   filesystem phases.

2. **`brain_dir` in dream JSON does NOT always match the engine target.**
   The JSON output reported `"brain_dir":
   "/data/hermes/users/rnr/brain-copy"` — Roshini's path — while the
   engine was actually running against Bharat's HOME
   (`/data/hermes/users/[REDACTED-TID]`). The `brain_dir` field is a label
   pulled from gbrain's loaded config; the engine runs against `$HOME`
   regardless. The 7 orphans / 0 pages-suggested / holder=garry signature
   confirms the engine was processing Bharat's data, not Roshini's.
   **Implication**: don't panic when `brain_dir` looks wrong — verify by
   the orphan count and the `propose_takes` scanned count matching the
   expected user's content, not by the literal `brain_dir` string.

3. **Bharat's config still uses `zeroentropyai:zembed-1` (Jul 14 2026).**
   Previous runs (Jul 4, Jul 10) used `minimax:embo-01`. The
   `.gbrain-writable/config.json` may have been rebuilt, or another
   config (default-path) is being read. Embed remains blocked on
   `ZEROENTROPY_API_KEY` until either (a) the key is provisioned, or
   (b) the embedding model is changed to one with a working credential
   (e.g. `minimax:embo-01` with `MINIMAX_API_KEY` set, or
   `openrouter:openai/text-embedding-3-small` with `OPENROUTER_API_KEY`
   exported from `~/.openrouter_key`).

4. **The default-scaffold fingerprint appeared** — 7 orphans out of 7
   pages, holder=garry, 0 resolved takes. This matches the
   "brain was never properly initialized" signature documented in
   the SKILL.md. Bharat's brain DB exists (PGLite at `.gbrain-writable/`)
   but the markdown content dir under `sales1.blr/brain/` was never
   populated. The dream cycle runs against the scaffold pages only.
   Fix: write actual `identity.md`, `notes/`, `people/`, `projects/`
   content for Bharat, or run `init --pglite --force` if the DB needs
   a fresh start.
