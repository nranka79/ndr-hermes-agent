## Recurring observations

1. **"Sync anchor ... gc'd, running full reimport" appears on every run for
   Bharat.** First seen in the 2026-07-10 reference (anchor 7789bb2 gc'd); now
   again with anchor `ec580838` gc'd. The root-owned brain dir's git history
   appears to be losing objects between runs — possibly a server-side `git
   gc` on the cron host, or the root user rewriting history (e.g. on
   `brain-copy` replacement cycles). Harmless (reimport is ~200ms, 1 page
   total) but worth flagging because it would inflate the page count
   dramatically on a brain with real content. The `gbrain-ops` SKILL.md
   Pitfalls section already documents this — the Bharat brain is the
   canonical reproducer.

2. **The 7 orphan pages are default scaffolding, not real content.** The
   brain's only markdown file is `identity.md` (126 bytes — placeholder), so
   gbrain reports 7 orphans (the 7 default scaffolding pages created by
   `init --pglite`: `identity.md`, `readme.md`, `notes/readme.md`,
   `people/readme.md`, `projects/readme.md`, `people/roshni-ranka`,
   `person/roshni-ranka`). These are scaffolding from a long-ago `init` call
   and have not been overwritten with Bharat's real identity. The SKILL.md
   warns about `identity.md` defaulting to username `garry` — that warning
   still applies to Bharat's brain.

3. **PGLite DB and `.gbrain-writable` config persist between cron runs.**
   No re-init needed; config.json stable since the 2026-06-28 init.
   Re-initialization is only needed if the config is cleaned up (as happened
   to the stale `sales1.blr` Postgres config between 2026-07-09 and
   2026-07-10) or if a migration blocks (e.g. v35 event trigger EACCES).

4. **Embed failure is a stable, expected platform limitation, not a rate
   limit.** `MINIMAX_API_KEY` is not set in the cron environment and the
   `OPENROUTER_API_KEY` env-var-delivery gap (see
   `references/openrouter-embedding.md`) prevents fallback to OpenRouter.
   This is not transient — re-running will produce the same embed=fail
   result until a key is provided.
