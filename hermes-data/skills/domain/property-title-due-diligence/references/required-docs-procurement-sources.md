# Required Documents — Procurement Sources

Source: Prakash's "Required Documents for Agriculture Lands in Karnataka.pdf" (Jun 2026).
This table shows where each of the 34 required document types is obtained from.

## A. Title Documents

| # | Document | Obtain From |
|---|----------|-------------|
| 1 | RTC (Record of Rights, Tenancy & Crops) – Latest Certified Copy | Village Accountant (VA) / Bhoomi Online |
| 2 | Form No. 7A Endorsement – Tahsildar (Granted Lands, Section 77A KLR Act) | Tahsildar Office, Ramanagar |
| 3 | Saguvali Chit / Grant Order (Original or Certified Copy) | Tahsildar Office / ADLR Office, Ramanagar |
| 4 | Granted Lands Endorsement – Permission for Transfer (Section 4 PTCL Act) | Tahsildar Office, Ramanagar |
| 5 | Parent / Mother Deed Chain – Title Trace (30-40 Years) | Sub-Registrar Office / From previous owners |
| 6 | GPA Registration Certificate & Validity Confirmation (if GPA used) | Sub-Registrar Office where GPA was registered |
| 7 | Legal Heir Certificate / Succession Certificate (if any owner is deceased) | Tahsildar Office / Civil Court |

## Usage

When building the Master Sheet per-Sy No tab, consider adding an "Obtain From" column after "Status" so the user can see at a glance where to procure each missing document. The procurement source varies by location — the Ramanagar addresses above apply specifically to the Lakshmipura / Bomvachanahalli project area.
