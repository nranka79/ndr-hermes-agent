# Premium FAR Cost Analysis — Bangalore Plan Sanctions

## Key concepts encountered during NDR's BuxRanka Hudson Circle cost research

### FAR Structure (Typical Bangalore Commercial Project)

| Component | Value | Notes |
|-----------|-------|-------|
| Base FAR | 2.5 | Standard for commercial in Bangalore |
| Amalgamation Benefit | 0.5 | If multiple sites merged |
| Premium FAR Loading | Up to 40% of Base FAR | Under Premium FAR policy |
| TDR Loading | Variable | Purchased separately |
| **Maximum achievable** | **4.5 FAR** | 2.5 + 0.5 + 1.0 (40% of 2.5) + 0.5 TDR |

### Premium FAR Official Charges Formula

> **28% × (Commercial Guideline Value × 1.5) × (Premium FAR %) × (Land Area in sqm) × (Base FAR)**

Worked example from BuxRanka Hudson Circle:
- 28% × (₹1,55,040/sqm × 1.5) × 40% × 6,720 sqm × 2.5 = **~₹45 Crores**

The "× 1.5" is a commercial uplift multiplier on the guideline value.

### Texworth Quotation Structure (Liaisoning Services)

For professional legal & liaisoning services to obtain modified plan sanction:

- **Base professional fee** — negotiated lump sum for the FAR enhancement scope
- **Payment stages**: Advance (~47%) → Mid (~47% on challan generation) → Final (~6% on delivery)
- **Exclusions**: All statutory/government fees, drawing preparation costs
- **Scope**: Complete handling from submission through obtaining sanction, all NOCs, external advisory

### Tracing Cost Calculation History from Gmail

When asked to find "the basis of calculation" for a project cost figure you sent to a partner:

1. **Search Gmail** for the project name + "Proposal" + key cost terms ("FAR", "Premium")
2. **Follow the thread backwards** — the earliest messages contain the original proposal with formulas
3. **Cross-reference with Drive** — look for BBMP fee calculators, cost spreadsheets shared as attachments
4. **Extract PDF quotations** attached to emails (these contain the professional fee breakdown)
5. **The Feb 10, 2026 email** from NDR to Godrej explicitly says: "This calculator should help you understand the excess charges for each new revision" — the BBMP calculator was the official reference document

### Estimating 4.0→4.5 Cost Enhancement

Simple proportional approach used by NDR:
- **Additional area**: 0.5 FAR × Site Area (∼79,000 sq ft) = ∼39,500 sq ft
- **Cost at ₹200/sq ft** (the per-sq-ft liaisoning charge for additional area): 39,500 × ₹200 = ₹79 Lakhs (before margin)
- **Alternative method**: Quotation for 1.0 FAR enhancement was ₹4.30 Cr → half that for 0.5 FAR → ∼₹2.15 Cr (but NDR specifically used the per-sq-ft method, not half-quotation method, for this estimate)
