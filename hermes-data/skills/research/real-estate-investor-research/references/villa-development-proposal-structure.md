# Villa Development Proposal — Document Structure Preference

## User (Prakash) Preference

For **Villa Development Proposals** / **Land Project Feasibility Reports**, the document should be structured with the **consolidated big-picture summary first**, followed by detailed sections.

### Approved Structure

**1. Land, Transaction & Project Realisation Summary** (front section — 3 blocks)
- **Land Overview**: location, area, yield, infrastructure summary
- **Transaction Structure (JDA)**: key terms table — land value, deposit, share percentages, villa allocation
- **Project Realisation (3 Scenarios)**: revenue, cost, profit, margin across price scenarios + breakeven

**2. Executive Summary** (condensed parameter table with thesis statement)

**3. Detailed sections follow** in this order:
| # | Section |
|---|---------|
| 3 | JDA Structure (key terms, yield calc, split) |
| 4 | Subject Land Overview (parameter table + key advantages) |
| 5 | Location Advantage (connectivity, economic drivers, social infra) |
| 6 | Villa Supply Gap Analysis |
| 7 | Competitor Landscape |
| 8 | Demand Drivers & Ecosystem |
| 9 | Target Buyer Profile & Sales Velocity |
| 10 | Project Cost Sheet |
| 11 | Revenue Projection |
| 12 | Profitability Analysis (3 scenarios) |
| 13 | Breakeven Analysis |
| 14 | Recommendation & Next Steps |
| 15 | Disclaimer & Data Sources |

### Why This Order Works

- **Front section = decision-making view**: The user sees the land, the deal structure, and the financial outcome in one glance
- **Executive Summary = quick-reference facts**: Supporting parameters in a clean table
- **Detailed sections = deep-dive**: Only read when needed for verification or presentation

### Verified On

- Bidadi ~10 Acres — Villa Development Proposal (JDA), July 2026. Original doc had Executive Summary first → restructured per this preference.
