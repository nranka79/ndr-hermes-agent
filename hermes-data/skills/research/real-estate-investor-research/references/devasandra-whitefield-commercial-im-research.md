### 4. Transaction Evidence Sources

To get verified transaction data for the IM:
1. **Sub-Registrar, Krishnarajapuram** — request recent commercial sale deeds in Devasandra/Whitefield
2. **Form 22 (Encumbrance Certificate)** — shows all registered transactions for a specific property
3. **Kaveri Online** — registered sale values (guidance + actual consideration)
4. **BMRDA** — development charge receipts showing assessed land values
5. **KIADB** — commercial land allotment rates (published periodically)

### 5. Web Research Limitations (Whitefield IM context)

- **99acres, MagicBricks, NoBroker** — all return 403/blocked from automated access
- **Government portals** (BMRDA, BBMP, Kaveri) — often timeout from server-side network restrictions
- **DuckDuckGo HTML** works for search; use browser-based DuckDuckGo as fallback
- **Industry reports** — Colliers/CBRE/JLL/Knight Frank sites are accessible via browser
- **Known working approach**: Use browser (camofox) for DuckDuckGo searches if available; otherwise compile from known market data and direct government portal URLs that the user can access themselves

### 6. Key Demand Drivers for Devasandra Commercial

- Proximity to ITPL (1-2 km) → office demand spillover
- Whitefield Main Road frontage → retail/commercial visibility
- Metro connectivity (Whitefield Metro operational) → significant value appreciation
- Kadugodi Tree Park Metro → transit-oriented development potential
- Residential catchment (Brookefield, Kundalahalli, Hopefarm) → retail/service commercial demand

### 7. Phase-to-Phase Verification

When compiling land value data for the IM, ALWAYS cross-check consistency:
- **GDV** = Plot Area × FAR × Capital Value per sqft
- **Expected Land Value** = GDV × 25-40% (land cost should be 25-40% of GDV)
- **If land rate < 10% of GDV** → almost certainly wrong (common IM error)
- **Guidance values** are typically 50-70% of true market value — use as floor, not ceiling

### 8. Competitor Projects Within 3 km

Map all major commercial developments within 3 km of the subject property:
- Project name, developer, total area, occupancy rate
- Rental rates (if available from market reports)
- Distance from subject property
- Year of completion / status
