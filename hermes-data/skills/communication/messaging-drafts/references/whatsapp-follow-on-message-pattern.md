# WhatsApp Follow-On Message Pattern

When sending a follow-on/additional message to a group chat where previous messages about the same topic were already sent:

## Rule
**Only include the NEW item being added. Do NOT repeat previously shared content.**

## Why
The previous messages were already delivered and acknowledged. A follow-on that re-lists everything makes the recipient re-read old information to find what's new, and wastes their attention.

## Examples

### ❌ Wrong — Full recap (what to avoid)
> Accounts Team — please process the following invoices for Kanta Ranka:
> 
> 1. Wax Removal + PTA — Rs 2,740
> 2. Lab Tests + OP Consultation — Rs 15,730
> 3. Anaesthesiology Consultation — Rs 700
>
> Total: Rs 18,470

### ✅ Correct — New item only
> Accounts Team — sharing one additional invoice for Kanta Ranka — Anaesthesiology Consultation (Dr. NS Chandra Shekara, Trustwell Hospitals, 09 Jul 2026 — Rs 700).
>
> [Drive Link]
>
> Please process. Debit from KDR's account and credit to Nishant Ranka.

## Trigger Recognition
The user typically signals this with phrases like:
- "This is a follow on message..."
- "In addition to what was already shared..."
- "One more..."

When you hear these, the pattern is: just the new payload, no recap.
