# OS Petition Under Section 92 CPC — Context & Response Template

## What It Is

An **Original Suit (OS)** under **Section 92 of the Code of Civil Procedure, 1908** is a legal proceeding filed by trustees of a public charitable trust seeking court permission to alienate (sell/transfer/lease) trust property. This is required because trust property is held for public benefit and the trustees need court supervision to ensure the sale is in the trust's best interest.

## The Court Process

```
Step 1: Misc(ellaneous) Petition filed
    ↓ (court hears and decides)
Step 2: Misc Petition ALLOWED → leave granted to file OS
    ↓ (if rejected, the process stops here)
Step 3: Original Suit (OS) filed under S.92 CPC
    ↓
Step 4: Court hearings (typically 6-7 hearings)
    ↓ (each hearing addresses different aspects)
Step 5: If no objections → Court GRANTS permission for sale
    ↓
Step 6: Trust can proceed with sale at fair market value
    (sale proceeds go to Trust account for charitable objects)
```

## When This Comes Up

- Legal due diligence for a property buyer (buyer's advocate asks "what is the OS status?")
- Bank or financial institution conducting title audit
- Investor requesting full legal documentation
- Any trust-owned property where court permission is required for sale

## Related Documents in the OS Process

| Document | What It Proves |
|---|---|
| Original Trust Deed | Trust was validly constituted for charitable purposes |
| Amended Trust Deed | Power to sell was added (Clause 14(f) typical) |
| Board Resolution | Trustees resolved to sell |
| Misc Petition Order | Court granted leave to file OS |
| OS Petition | Main suit seeking sale permission |
| Valuation Report | Government-approved valuer's assessment |
| Court Order (Final) | Permission granted — sale can proceed |
