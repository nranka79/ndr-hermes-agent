# Consolidating scattered files into ONE evidence pack

NDR regularly asks: *"find the files in the folders all over my drive and move them into one single
pack"* (Mirabilis/Behera, Ranka Iris khata, Dinesh Ranka tax D1–D8). The pack, not the chat, is the
deliverable. Pattern that worked:

## 1. Structure
One parent folder under `TMP`, named for the client/matter and the scope (state the scope explicitly,
e.g. "all demands", not one incident). Then **one subfolder per item** — `01_D1_…`, `02_D2_…` — because
that is how he thinks about the matter. Plus cross-cutting folders: `00_Master_Index_and_Schedule`,
`09_<settled/excluded items>`, `10_Source_snapshots`, `11_Multi-item_documents`,
`12_Analysis_and_Registers`, `13_Underlying_filings`.

## 2. Move vs copy — the ownership rule
- Files NDR owns: **move** (`files().update(addParents=dest, removeParents=old)`).
- Files/folders owned by someone else (e.g. `admin2.blr@draas.com`, `akaushik@draas.com`) and merely
  shared into his view: **move fails** with `403 Increasing the number of parents is not allowed` —
  on the folder AND on each child. **Copy instead**: `files().copy(fileId=…, body={'parents':[dest]})`
  yields a permanent, NDR-owned copy. Leave the original untouched.
- Say plainly in the report what was moved and what was copied, and that originals are intact. He
  cares about provenance not being silently rewritten.

## 3. Empty folders are a finding
If an item genuinely has no documents, still create its folder and drop
`READ ME — … there are no documents yet.txt` inside, naming the key identifiers and exactly what is
missing. Otherwise the next reader (or NDR) reads the empty folder as an oversight.

## 4. The index sheet
A Google Sheet in `00_`: one tab per axis (per-item schedule with a `=SUM()` total row; a
"what we said vs what they said vs what paper we hold" tab; a numbered gaps tab with owners; an
excluded/settled tab; a `Document Index` tab generated by walking the folder tree — folder path | name
| type | size | link). Build with Sheets API, then batchUpdate formatting: frozen header row + frozen
first two columns, wrap, `"₹"#,##0` money format. `properties.locale` must be `en_GB` (not `en_IN`);
`values().get` uses `valueRenderOption`.

## 5. Housekeeping in the report
Give the pack link and the sheet link at the top, the one-line total, per-item amounts, the "empty on
purpose" list, and what was moved vs copied. Retire the old container explicitly ("the old folder is
now empty — stop sending people there") so future sessions don't cite a dead path.
