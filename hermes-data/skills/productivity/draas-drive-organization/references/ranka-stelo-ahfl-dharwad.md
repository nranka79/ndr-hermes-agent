## Pitfalls learned

- File named "12. Stelo Fire NOC FINAL.pdf" is a 5-page BUNDLE: p1 = HDMC Building
  License Approval (plan sanction, Kannada), p2 = Fire NOC amendment (DGP), p3 =
  Water Board NOC, p4 = HESCOM NOC, p5 = HESCOM fee receipt. Don't conclude from
  the filename alone.
- Many scans are CamScanner PDFs with no text layer → render pages with pymupdf
  at dpi≥150 and OCR each PNG via vision_analyze (Kannada OK). Accept OCR
  transcription for bilingual docs. Multi-page bundles: OCR every page — a
  single "Fire NOC" filename can hide 5 distinct documents (see above).
- BSNL / Water Board / Electricity NOC *applications* (JPGs) exist but are
  application copies, not the granted NOCs — verify what you're reporting.
- Master Index (AHFL_Master_Index) writes have duplicate/variant rows
  (e.g. "Addendum to Sharing Agreement" 15.06.2013 vs 28.09.2020, "Certificate of
  Registration" typos) — dedupe by date+doc no before quoting.
