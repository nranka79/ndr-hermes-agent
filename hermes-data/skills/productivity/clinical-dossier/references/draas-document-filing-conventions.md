# DRAAS Document Filing Conventions

**Domain reference for clinical-dossier skill** — Governs where and how personal/family documents are filed on Drive. Based on user corrections during certificate filing (Jun 2026).

## Folder Structure

All personal documents go under the **Personal** folder (Drive ID: `0B1Oc8cSaJXPGYkQtYXJDQWVBUVE`). Each family member has their own folder:

```
Personal/
├── Ruhaan/        (ID: 0B1Oc8cSaJXPGbl9VMEZBdE04Z28)
├── Rivaan/        (ID: 0B1Oc8cSaJXPGV1p3ZFg2S0xJVUk)
├── ... (other family members)
└── Ruhaan Medical/ (separate folder for medical records)
```

## Certificate Filing — Naming Convention

Standard format for academic/co-curricular certificates:

`YYYYMMDD Provider Name Grade X Subject Level X Certificate - Result - ChildName.pdf`

Examples from this session:
```
20251127 Trinity Grade 4 Acting Level 2 Certificate - Distinction - Ruhaan Ranka.pdf
20251127 Trinity Grade 4 Speech and Drama Level 2 Certificate - Merit - Rivaan Ranka.pdf
```

## Exam Report Sheets

For accompanying report/evaluation sheets, use:

`YYYYMMDD Provider Name Grade X Subject Exam Report Sheet - ChildName.pdf`

Examples:
```
20251127 Trinity Grade 4 Acting Exam Report Sheet - Ruhaan Ranka.pdf
20251127 Trinity Grade 4 Speech and Drama Exam Report Sheet - Rivaan Ranka.pdf
```

## DO NOT

- Create combined folders like "Ruhaan & Rivaan Docs" — each child has their own folder under Personal
- File documents in root-level folders or orphaned folders with no parent
- Use informal naming — always include date + provider + subject + result + child name
