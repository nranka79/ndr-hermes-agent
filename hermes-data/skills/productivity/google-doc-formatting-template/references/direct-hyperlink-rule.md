# Direct Hyperlink Rule for Nishant Learning Documents

**Rule (Non-Negotiable):** Every time a learning, tutorial, reference, or "daily learning resource" document is created for Nishant, **every single mentioned resource must be a direct clickable hyperlink**. 

Never write:
- "Search for 'Hermes Agent session management' on YouTube"
- "See the X thread by @Teknium"
- "Check the official docs"

Always write:
- Official Session Management Documentation: https://hermes-agent.nousresearch.com/docs/features/sessions
- X Thread by @Teknium on v0.18 Judgement Release: https://x.com/Teknium/status/2074639961727655959
- YouTube search for practical examples: https://www.youtube.com/results?search_query=Hermes+Agent+session+management+tutorial

## Template Phrases to Use

**Good:**
- Official documentation: [Session Management](https://hermes-agent.nousresearch.com/docs/features/sessions)
- X thread by @Teknium (July 2026): [v0.18 Judgement Release — session pruning and export](https://x.com/Teknium/status/2074639961727655959)
- YouTube tutorials: [Hermes Agent Browserbase + browse.sh playbooks](https://www.youtube.com/results?search_query=Hermes+Agent+Browserbase+browse.sh+playbooks)

**Bad (do not use):**
- "Look at the X posts about this"
- "There are several YouTube videos"
- "See the official documentation"

## Why This Matters
Nishant uses voice messages and wants to click through immediately while listening to the voice note or reading the doc. Summaries without links waste his time.

This rule applies to **all** productivity/learning documents created for him. It was reinforced multiple times in July 2026 sessions when previous versions only summarized resources without hyperlinks.
