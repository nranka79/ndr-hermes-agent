## The procedural chain

A converted (CLU / residential) plot can be reverted to agricultural status only by the DC who
issued the conversion order, and only after the Tahsildar reports that the land is undeveloped.

```
Trust → DC                     : request to cancel conversion order, restore agricultural status
DC → Tahsildar                 : "inspect the land, verify whether any development has taken
                                  place, submit a detailed report with your clear recommendation"
Tahsildar → DC                 : inspection report + recommendation
DC                            : cancellation order (then 5-year non-conversion restriction)
```

**Do not conflate the stages.** Each has its own document and its own legal weight — see the
status ladder below. Read the *operative sentence* of whatever document you hold; DC letters
state their own nature explicitly ("you are hereby requested to examine and ascertain…", "you
are directed to provide your clear opinion / detailed report").

## Pitfalls

### ⚠️ The DC's letter to the Tahsildar is a REQUEST, not a cancellation order

The English translation we hold says so in its own footnote, and the body confirms it. Any
summary, briefing, or outbound letter that describes this stage as an order, a direction, or an
accomplished fact is **wrong**. Correct phrasing: *"the reference before you records no
development on the land"* — never *"the Tehsildar has found no development."*

### ⚠️ Two different dates exist for the Trust's own request

The DC's reference (1) cites the Trust's letter as **26-12-2025**; the letter we hold on Drive is
dated **20-11-2025**. Possibly two separate letters, possibly a transcription difference in the
DC's office. **Flag it, do not pick one.** Confirm against the signed original before quoting.

### ⚠️ The BIAAPA 12-07-2021 order is superseded, not live

Do not present BIAAPA's residential land-use change as a current constraint. The 28-07-2021
conversion OM is the operative order; BIAAPA's order is its predecessor by virtue of the master
plan. In a reversion request the BIAAPA order only matters as the record that no layout was ever
sanctioned on it.

### ⚠️ The 5-year non-conversion restriction runs FORWARD from cancellation

The undertaking to accept it is part of the *ask* — it does not already bind the Trust while the
application is pending. Frame it as an undertaking the Trust accepts, not as a restriction
already in force.

## Status ladder — enforce it in every draft or briefing

| Stage | Document that proves it | Weight |
|---|---|---|
| Trust applied | Trust's request letter to the DC | Application only |
| DC forwarded for report | DC letter to Tahsildar | **Request, not order** |
| Tahsildar reported | Tahsildar's inspection report | Finding — *confirm it exists before citing* |
| DC cancelled | Cancellation order from the DC | The only operative instrument |

When NDR describes progress from memory ("it has undergone all processes, Tehsildar has
confirmed, BIAAPA has confirmed"), **check each rung against a document** and report the rungs
that are not yet evidenced. This is the single most consequential error in this matter class: a
fabricated completed finding, spoken in a senior official's voice, to a government authority.

## Where this skill stops

Once a message must be authored **in a third party's voice** (an MP writing to a DC, an
intermediary forwarding as-is), the drafting side is governed by
`messaging-drafts → references/third-party-message-via-intermediary.md`. This file supplies the
legal facts and status; that file supplies the voice and fact-hygiene rules. Use both together.
