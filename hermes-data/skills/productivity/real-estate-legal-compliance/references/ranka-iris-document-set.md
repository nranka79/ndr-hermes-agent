## Usage Notes for Future Agents

- **When user asks for "links" or "folders":** Provide the Google Drive folder links as the primary answer, then local paths as fallback. DRAAS users prefer clickable Drive links over file paths.
- The **Customer Legal Set 16MAY16** folder is the richest single source — it has sale deeds, NOCs, tax receipts, and ECs as individual PDFs. Point users there first.
- For mother deeds: Docs #009 and #013 are the operative deeds (original owner → DRA). Docs #004, #007, #011 are BDA-to-original-owner deeds (title chain origin).
- **Multiple Drive folders exist for the same project** — different DRAAS team members have copies in their individual Drives. If a user says they can't access a folder, try another folder ID from the list above.
- OCs may arrive in a separate "Main" folder (newest) while the historical legal set stays in "Customer Legal Set" or "Old" folders.
- Tax paid receipts after FY2015-16 may not be in the legal index — check both the Customer Legal Set folder AND the `downloaded_docs/` local directory for recent years.
- The Legal Set Document Index spreadsheet has Dropbox links embedded (legacy) — those links may be dead; use Drive links instead.
- When presenting to the user, organize by **revenue document category** (OC, CC, mother deed, tax receipt, EC) rather than by index number — that's how they think about it.
