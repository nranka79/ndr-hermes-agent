### Pitfalls (carried forward)

- **TDR certificate is not a standalone file** — point to the sanction plan drawing's TDR Utilization Table.
- **Scanned Kannada government PDFs have no usable text layer** — `pdftotext` returns
  page-break noise. Render with `pdftoppm -r 150 -png` then read pages with
  `vision_analyze`. Do this before claiming a document is unreadable.
- **Sanction plan PDF is 4.8 MB, 1 page** — large-format drawing; TDR table is lower-right.
