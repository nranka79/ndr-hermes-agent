# Ranka Iris — BWSSB NOC & BBMP road-cutting permissions

Verified 2026-10-09 against Drive (google-draas). Question class: *"what does the BWSSB road
cutting permission say about pipes / how many pipes, what diameter, and does it let us connect
the sanitary and inlet pipe?"*

## Headline finding — there is NO BWSSB road cutting permission for Iris

Road cutting in Bengaluru is a **BBMP** matter. **BWSSB** issues the *NOC* (water supply + UGD
connection); it does not issue a road-cutting/excavation permission. A drive-wide name search for
`road cutting` plus a `fullText contains 'BWSSB' and fullText contains 'Domlur'` sweep returned no
BWSSB cutting permission. **Do not promise one.** If NDR believes one was issued, it is either
with the contractor (Gopal Sanitations / Shankar Electricals), with BWSSB, or was never taken.

## Traps

- **The pipe-size language lives in a DIFFERENT project's NOC.** `BWSSB_WaterAndSewageNOC_2016_Expired.pdf` (`12eP9uCkiRdNFRqclQkaPjgxUwFlyILhg`, owner sales1.blr) is **not Iris** — it is **Sy 14/1 Allalasandra, Yelahanka** (72 units, near Allalasandra lake). It *does* state "100 mm dia existing water supply pipeline" and condition (d) "100 mm dia DI pipes and 150 mm to 230 mm GSW UGD line". Never quote it as Iris.
- **`20160805_RankaIris_BBMP_RoadCuttingPermission...` and `20260804_...RoadCuttingPermissionReceipt...` are the SAME Aug-2026 permission+receipt pair** — the "2016" file is a mis-named duplicate scan of the same letter the 2026-named file holds. Don't present them as two separate permissions.
