# DRAAS Drive File Naming Convention — Legal Documents

As directed by Nishant (ndr@draas.com) — applies to all legal documents filed on Google Drive for DRAAS projects.

## Core Rules

1. **Project name first** — use the project's market-facing name (e.g. "Serenity Hillview Land", "Ranka Amber")
2. **Abbreviate legal entities** — use standard short forms:
   - Godwad Bhavan Jain Trust → **GBJT**
   - DRA Realty → **DR**
   - DRA Aadithya South City Projects → **DRA-ASCP**
3. **Include court case number** — e.g. `O.S. 7575_2026` or `Misc. 210_2026`
4. **Skip survey numbers** — when the project name already identifies the land (Sy.No.93/2 is understood for "Serenity Hillview")
5. **Skip full trust/entity names in filenames** — the abbreviation suffices; full name lives in the document itself

## Examples

| Old (wrong) | New (correct) |
|---|---|
| `2026_OS_GodwadBhavanJainTrust_Sy93-2_Hurulagurki_SerenityHillview.pdf` | `2026_OS_7575_Serenity_Hillview_Land_GBJT.pdf` |
| `20260715_Misc_Petition_210_of_2026_Godwad_Bhawan_Jain_Trust_entire_file.pdf` | `2026_Misc_210_Serenity_Hillview_Land_GBJT.pdf` |

## Order of elements

`<YEAR>_<DOCUMENT_TYPE>_<CASE_NUMBER>_<PROJECT_NAME>_<ENTITY_ABBREV>.pdf`

- **YEAR:** 4-digit (2026)
- **DOCUMENT_TYPE:** OS, Misc, Sale Deed, Trust Deed, CLU, etc.
- **CASE_NUMBER:** Court-assigned number (7575, 210, etc.)
- **PROJECT_NAME:** Market name in Title_Case (Serenity_Hillview_Land)
- **ENTITY_ABBREV:** Trust/company short form (GBJT)
