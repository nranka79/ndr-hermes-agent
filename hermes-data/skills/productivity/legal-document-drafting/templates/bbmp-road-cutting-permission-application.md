# BBMP Road Cutting Permission Application — Template

## Context

Use this template when a DRAAS project has received its Occupancy Certificate (OC) and needs road-cutting permission from the BBMP ward office (typically Domlur or the project's jurisdiction) to lay cables/pipes for BESCOM (power) and BWSSB (water/sewerage) connections.

**Two separate applications are needed** — one for BESCOM, one for BWSSB. Each goes to the Executive Engineer at the relevant BBMP Ward Office. The structure is identical; only the purpose and enclosure lists differ.

## Key Details to Fill

| Field | Where to find |
|-------|--------------|
| BBMP Sanction No. + Date | Drive search: "BBMP Sanction" + project name |
| OC receipt date | Drive search: "Occupancy Certificate" + project name |
| Road name adjacent to site | Project location / site address |
| Cut length × width × locations | Site survey / engineering estimate |
| Road type (BT/CC) | Visual inspection or site plan |
| Applicant mobile no. | User profile |

## Template — Application Letter

**From,**
[Name]
[Designation]
[DRA Developers / DRAAS]
Bangalore

**To,**
The Executive Engineer
BBMP — [Ward Name] Ward Office
[Ward Area], Bangalore

Date: __/__/2026

**Subject: Application for Road Cutting Permission for [BESCOM/BWSSB] [Power/Water & Sewerage] Connection — [Project Name], [Area] — Reg.**

Sir/Madam,

We are writing to request permission for road cutting at the below-mentioned location in connection with obtaining [BESCOM power connection / BWSSB water supply and sewerage connections] for the [Project Name] project situated at [Project Location], Bangalore.

**Project Details:**
- **Project Name:** [Project Name]
- **Location:** [Full Address / Survey Details]
- **BBMP Sanction:** [Sanction No.] dated [DD-MMM-YYYY]
- **Occupancy Certificate:** Received (dated DD-MMM-YYYY)

**Purpose of Road Cutting:**
We require road cutting permission for laying [electrical cables / water supply pipelines and sewerage pipelines] from the [BESCOM/BWSSB] mains to the project site for availing permanent [power / water & sewerage] connection to the above-mentioned building. The Occupancy Certificate for the project has been received and we now need to complete the [BESCOM/BWSSB] connection for handover of units.

**Details of Road Cutting Required:**
- Location of Cutting: [Road name/street adjacent to the property]
- Length of Cutting: _____ meters
- Width of Cutting: _____ meters
- Number of Locations: _____
- Type of Road: [BT/CC]

**Undertaking:**
We hereby undertake that:
1. Proper barricading with cautionary tape and lights will be provided during the work.
2. The road cutting will be done using a road-cutting blade in a regular/square shape.
3. The excavated material will be carried away immediately and the cut portion filled with inert material (M-sand/stone dust) compacted in layers.
4. The excavated earth will not be backfilled.
5. The work will be completed within 30 days of receipt of permission.
6. We shall remit all applicable fees as demanded by the BBMP for restoration of the road.

**Enclosures:**
1. Copy of Occupancy Certificate
2. Copy of BBMP Plan Sanction
3. Site plan showing exact location of road cutting
4. Ward map showing road cutting locations
5. Copy of property tax receipt
6. [BESCOM NOC / BWSSB application copy]

We request you to kindly accord permission for the same at the earliest and oblige.

Thanking you,

Yours faithfully,

**[Name]**
[Designation]
DRA Developers
Mobile: ____________
Email: ____________

## Reference Format Source

Derived from the standard government FORM-RC-1 (Road Cutting Application) used by municipal corporations in India. The Tamil Nadu Government's version was used as reference (available at `tnurbanepay.tn.gov.in/Road Cutting-Application.pdf`) — the structure and conditions (barricading, blade cutting, 30-day completion, permanent restoration by ULB) are generic across Indian states including Karnataka/BBMP.
