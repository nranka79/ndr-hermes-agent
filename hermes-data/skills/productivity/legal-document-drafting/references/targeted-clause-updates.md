# Targeted Clause Updates — Precision Rules

## When updating a specific clause in a legal document

### DO:
- Update ONLY the exact clause/text the user specified
- Extract ONLY the specific account/item the user named (e.g. "100% RERA Collection Account" — not all three accounts)
- Preserve all other content verbatim
- If the original is a PDF: state the exact change and offer the replacement text or create a Google Doc with just the changed clause in proper context

### DON'T:
- Restructure the document or add clauses the user didn't ask about
- Include additional bank accounts, schedules, or detail beyond what was requested
- Create a new document with only the updated sections missing the original structure
- "Improve" other parts of the document while you're at it

## Example
User: "Update Clause 2 with the RERA collection account bank details"

✅ Correct: Insert only the 100% Collection Account (Name, A/c No, Bank, Branch, IFSC) into the blank in Clause 2. Leave everything else untouched.

❌ Wrong: Insert all three accounts (Collection + Designated + Operative). Add a note to Schedule C. Create a whole new document.
