# Section 281 Income Tax Application — Drafting Pattern

## When to Use
An application under Section 281 of the Income Tax Act, 1961 is filed when a person proposes to transfer assets and needs prior approval from the Income Tax Department to ensure the transfer is not void against any tax liability.

## Structure

### Part 1 — Covering Letter
1. **From**: Applicant (name, PAN, address, phone, email)
2. **To**: The Assessing Officer, Circle __(__), [AO Office Address]
3. **Subject**: Application for prior approval under Section 281 of the Income-tax Act, 1961
4. **Body**:
   - Paragraph 1: Identity of applicant, PAN, tax residency, filing history
   - Paragraph 2: Description of proposed transaction
   - Paragraph 3: Tax compliance table (last 3 AYs — date of filing, returned income)
   - Paragraph 4: Declaration of no outstanding tax demands (with screenshot from IT portal)
   - Paragraph 5: Prayer for approval
5. **Enclosures list**: Annexure 1 (ITR Vs), Annexure 2 (demand screenshot), Annexure 3+ (underlying documents)

### Part 2 — Form ITNS 281 (Application proper)
- Personal details
- Description of assets/property
- Proposed transaction details
- Declaration

## Key Details Needed
| Detail | Where to get it |
|--------|----------------|
| PAN | User / Contribution Deed / PAN card PDF on Drive |
| AO Circle | User (placeholder if unknown) |
| Address, Phone, Email | User / Google Contacts |
| ITR filing history (3 AYs) | User / CA |
| Asset/property description | Partnership Deed Schedules |
| Underlying deeds (Sale Deeds, GPAs) | Drive / User |

## Who Files
- The Section 281 application is filed by the **CURRENT TITLE HOLDER** — the individual or entity that owns the assets being transferred
- If the transferor is a dissolved firm whose assets were partitioned, file a SEPARATE application for the dissolved firm (by way of abundant precaution) in addition to the individual partner's application
- The RECEIVING entity (partnership firm) does NOT file the application

## Attachment Pattern (from Kanta Ranka example)
- Annexure 1: ITR V acknowledgements for AY 2022-23, 2023-24, 2024-25
- Annexure 2: Screenshot of outstanding tax demand status from income tax portal
- Annexure 3: Copy of the underlying document (Partnership Deed, Sale Deed, etc.)
- Annexure 4: Schedules of properties being transferred
- Annexure 5: Any other supporting documents (Partition Deeds, GPAs, Agreements of Sale)
