## Workflow for Ward Verification

1. **Khatab first** — gives Old Ward + New Ward baseline
2. **OC Letter** — BCCC department letter; use for sanctioned ward (usually New Ward)
3. **BBMP Demand Challan** — administrative fee demand; often uses Old Ward
4. **Registered documents** — Gift/Partition/Sale Deeds; ward from executing party's address (not property location)
5. **Cross-check:** Old Ward in Khatab should match BBMP challan; New Ward should match OC Letter
