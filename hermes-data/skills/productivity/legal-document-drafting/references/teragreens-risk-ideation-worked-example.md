## Document structure used

### Header
```
# [Entity Name] LLP → Pvt Ltd: Comprehensive Risk Ideation & Mitigation Note
**Discussion draft — for review before drafting Shareholders Agreement**
**Date:** [original date] (Updated [update date])
**Partners:** [Name 1 (X%), Name 2 (Y%), Name 3 (Z%)]
```

### Briefing Note (Preamble)
A neutral, non-accusatory preamble explaining the document's philosophy:
- This is a collaborative ideation note, not a final agreement
- Purpose: think through every possible scenario, including uncomfortable ones
- Intent is NOT to assume bad faith — it's because you respect the partnership that you address friction points upfront
- "What could go wrong between reasonable people who want to stay reasonable" framing
- If any item reads as targeting a specific partner, that's a drafting failure — flag and rephrase
- Goal: fair dispute resolution, clean exit, documented procedures, zero operational disruption

## Key lessons from this engagement

1. **Language neutrality is critical** — never name a specific partner in an example. Use "one partner" / "a partner" throughout. Examples like "Salman (execution) wants Contractor A" were flagged and changed to "Partner responsible for execution wants Contractor A."

2. **Always update the existing doc, never create new versions** — the user explicitly said to maintain a single living document, not versioned copies.

3. **Folder ownership matters** — verify the target folder is owned by the user before uploading. If the user flags ownership, search for folders they own and present options. The correct folder is a user-owned entity folder (e.g., TerraGreens), not a shared/designer-owned project folder.

4. **Expense reimbursement is a first-class risk** — even small unrecorded expenses build resentment. Document a clear process: pre-approval threshold, receipts, monthly reconciliation, 15-day reimbursement cycle.

5. **The neutral entity principle deserves its own Part II** — don't bury it in a single bullet under governance. It spans hiring, office, brand, data, banking, procurement, IT access, insurance, and dispute resolution.

6. **Preamble sets the tone** — a well-written briefing note at the top prevents partners from feeling attacked when they read the risks.
