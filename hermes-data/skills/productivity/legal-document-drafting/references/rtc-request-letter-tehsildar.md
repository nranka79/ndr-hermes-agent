# RTC Request Letter — Karnataka Tehsildar

Standard format for requesting certified RTC (Record of Rights, Tenancy and Crops) extracts from the Tehsildar / Tahsildar office in Karnataka.

## When to use

User asks to draft a letter to the Tehsildar requesting RTC records for historical periods (e.g. 1960–2002), mutation entries, or certified copies of records of rights.

## Structure

### Header (applicant details)
- Full name (and alias/nickname in brackets, e.g. "Vinod Kumar Das (Rahul)")
- Address
- Phone number
- Date

### Addressee
```
To,
The Tehsildar,
[Taluk Name] Taluk,
[Hobli], [District],
Karnataka.
```

### Subject line format
```
Sub: Request for issuance of RTC (Record of Rights, Tenancy and Crops) extracts from the year [YYYY] to [YYYY] in respect of Survey No. [X] and Survey No. [X/X] of [Village] Village, [Hobli] Hobli, [Taluk] Taluk, [District] District – Reg.
```

### Body
1. Self-introduction: "I, [Name] (Alias), S/o [Father's Name], R/o [Address], hereby request you to kindly issue the certified copies of RTC extracts pertaining to the following lands for the period from the year [start] to [end]:"
2. Land details table:
   - Village, Hobli, Taluk, District
   - Survey No(s). (list each separately)
3. Purpose statement: "required for verification of title and for legal/property documentation purposes"
4. Fee readiness: "I shall pay the requisite fee as prescribed by the Department."

### Enclosures
1. Copy of Aadhaar Card / Photo ID proof of the applicant
2. Copy of latest RTC / mutation extract of the above survey numbers (if available)
3. RTC for the year [current year-1]–[current year] for reference *(use the most recent completed financial year)*
4. Any other supporting documents

### Signature block
```
Thanking you,

Yours faithfully,

Signature: ______________
[NAME (ALIAS)]
Phone: [number]
```

## Pitfalls
- **Father's name placeholder** — always mark `[Father's Name]` clearly. User may not supply it; leave the placeholder, don't invent.
- **RTC period** — after 2002 Karnataka RTCs are computerised (Bhoomi). Pre-2002 = manual records; the Tehsildar may levy search fees per year/survey number.
- **Tehsildar vs Tahsildar** — Karnataka uses both spellings; "Tehsildar" is standard in Bengaluru Urban district correspondence.
- **Outdated RTC enclosures** — the user may specify a particular year's RTC as reference (e.g. "RTC 25-26"). Use that literal reference, not a generic "latest RTC".
- **Applicant name with alias** — if the applicant goes by a nickname or alias (e.g. "Vinod Kumar Das (Rahul)"), include it in brackets after the full name throughout the letter.
