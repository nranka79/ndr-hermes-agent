- **Resolution needed:** Confirm whether BKT 2227 and SHV-1-02227 refer to the same registration entry or are separate entries

- **In PSA (Mar 2026):** REDSOUL = "Investor" — contributes ₹50L equity + up to ₹2.5Cr debt to DRA Realty

- PSA (8 pages) contains no figures for: total built-up area, FAR achieved, carpet area, number of floors, unit count
- Investor (Manjunath Singh) has no documented basis for project size in the PSA itself
- All project scale information depends on verbal representations from DRA

### 🚩 4. e-Stamp Purchase vs. Execution Date — 4-Month Gap
- e-Stamp purchased: **24-Nov-2025** (certificate issued)
- Agreement executed: **16-Mar-2026**
- Gap: ~4 months
- Standard practice: stamp purchased at or near execution
- Possible explanation: verbal agreement existed from Nov 2025; stamp purchased in advance; formal signing delayed
- Flag: verify if any other documents (emails, WhatsApp) reference the arrangement in this window

### 🚩 5. 12-Month Distribution Timeline — Ambiguous Trigger
- PSA Clause 4.3: "Company must finalize Project accounts and distribute Investor's share within 12 months of Project completion and sale of all units"
- Who determines "project completion"? No definition.
- If one unit unsold at project completion, does the 12-month clock never start?

### 🚩 6. Overhead Cap — "Total Project Revenue" Undefined
- 5% overhead cap stated, but "Total Project Revenue" is not defined in PSA definitions section
- Interpretation ambiguity: revenue before tax, after tax, including parking income, excluding registration fees?

### 🚩 7. Age Same for Raghu and Farida — Both 67

- Farida is Raghu's wife (per Addendum)
- Both being exactly 67 is possible but unusual — verify if DOB on file

### 🚩 8. PSA Contains Only 7 Schedules (A+B) — Not Full JDA Schedules

- PSA "Schedule B" is the Payment Plan only (₹50L, timing, mode)
