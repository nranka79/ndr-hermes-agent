## Golden rule: surgical edits only

**Change ONLY what the user explicitly asked you to change. Do NOT add, remove, or reformat anything else.**

Nishant has repeatedly corrected the agent for making wider changes than requested:
- "don't change any other details, I asked only to update clause 2" — when the agent also updated Schedule C with bank details
- "wrongly done" / "just list out table" — when the agent created a colored sketch instead of a simple tabular format

## Signals that the user wants a surgical edit

| Signal | Meaning |
|--------|---------|
| "update clause X with Y" | Do only that clause, nothing else |
| "can you just [verb]" | The "just" signals narrow scope |
| Specific instruction about WHAT to change without saying to reorganize | Assume everything else stays as-is |
| "don't change any other details" | Explicit — obey literally |

## Exceptions (when wider changes ARE appropriate)

- The user explicitly says "revise", "rewrite", "restructure", "replace", "update the draft"
- Cross-references would break without updating them (e.g., schedule numbering)
- A clause mentions a deleted section — update the reference only

## When the user asks for "just a table" or "just list out" — give them a table, not a visual

If the user asks for a tabular format of data extracted from a document:
- **Do NOT** create a map, sketch, image, or visual artifact
- **Do NOT** add decorative formatting, colors, or embellishments
- **DO** present the data as a structured table — Google Sheets, markdown table, or Doc table
- The user means "columns and rows" when they say "table"
