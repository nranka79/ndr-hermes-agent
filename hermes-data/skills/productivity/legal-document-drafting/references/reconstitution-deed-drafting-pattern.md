# Reconstitution Deed Drafting — Pattern & Workflow

## When to Use
Create a Deed of Reconstitution when existing partners of a registered partnership firm want to change the firm's name, profit-sharing ratio, capital structure, or governing terms — without dissolving the existing firm and creating a new one.

## Workflow

### Step 1: Read Source Documents
1. **Original Partnership Deed** — date, parties, registration number (Firm No.), capital/ratio terms
2. **Target/Reference Deed** — the deed whose terms will govern post-reconstitution
3. **Executed PDF** — ALWAYS check the signed PDF, NOT just the Google Doc draft. The PDF may differ in parties, recitals, and consenting parties.

### Step 2: Map the Asset Chain
Trace how each partner acquired their assets for Recitals:
- Original firm dissolution → Partition Deed → Allocation to partners
- Note Partition Deed date and registration number

### Step 3: Structure
**Parties**: Only CURRENT continuing partners. Remove dissolved firms or consenting parties.

**Recitals (A-F)**:
- Original partnership deed (date, firm name, registration no.)
- Intervening events (dissolution, Partition Deed)
- Each partner's allocations
- Partners' agreement to reconstitute

**Operative Clauses**:
- Article 1: Reconstitution — name change, ratio change, supersession
- Articles 2+: Adopt target deed terms, renumbered

**Capital Contribution**:
- Show ALREADY CONTRIBUTED separately from BALANCE
- Conditions precedent: Section 281, GST document return, legal DD, title opinion, ECs, revenue records
- Reference separate Contribution Deeds

### Step 4: Clause Modifications from Reference Deed
- **PTCL**: Generalize 18→24 months. Land not cleared = excluded, capital reduced
- **Section 281**: Condition precedent only — NO standalone article, NO suspension
- **Cheque**: Use NEXT sequential number (extract from existing cheque PDF on Drive)
- **Bank A/c**: Reference original firm's bank account

### Step 5: Track Changes in RED
- All edits in RED (rgbColor red=1.0) — user preference
- RED placeholder notes at bottom
- Edit existing doc, do NOT create new version

## Step-by-Step Change Document
When delegating edits to a colleague:
1. Create Google Doc: `YYYYMMDD_STEP_BY_STEP_CHANGES_[source]_TO_[target]`
2. Sections A-I with numbered steps
3. Each step: "Delete from:" / "Replace with:" with code-block text
4. Include options note (edit base doc vs reformat target doc)
5. Quick-reference summary table
6. 7-day editor access
