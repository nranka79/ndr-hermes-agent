### 1. LP Number — SSA References `BBMP/CC/4247/26-27` But License Has Different Numbers

- **Actual License:** `GBA/MDP/DDTP/0007/26-27` (file reference) · `GBA/BECC/0540/25-26` (project number)
- **Question:** Is `BBMP/CC/4247/26-27` a generic format that maps to one of the above? Or is the SSA referencing a separate/amended LP?
- **Impact:** All schedules and references in the SSA that cite this LP number may be pointing to the wrong document

### 2. Total Built-up Area — SSA States 4,686.72 sq.m But BBMP Sanctioned Only 3,383.17 sq.m
- **Difference:** 1,303.55 sq.m (~3,900 sq ft) — SSA is38.5% larger than BBMP sanction

- **Question:** Is there a revised/amended sanction plan with expanded BUA? Or is the SSA using a pre-sanction area figure?

### 3. Developer Name Typo in Building License
- License says "DRA REALIY PRIVATE LIMITED" (missing 'T')
- SSA and all other docs say "DRA REALTY PRIVATE LIMITED"
- **Action:** Request BBMP correction before OC stage

### 4. Project Name "RANKA AMBER" Not in Sanction Docs

- SSA Clause4 names the project "RANKA AMBER"
