# WhatsApp Sales Conversation Personas — 8 Archetypes

These personas emerged from analyzing 171 real estate sales conversations. Use them as templates when auditing a sales AI agent's chat logs.

## P1: Silent Expresser
- **Tagline:** "Yes I'm interested" — then disappears forever
- **Frequency:** ~30% of all leads
- **Behavior:** Responds to outreach, agent asks a question, user never replies again. Usually 3 messages total.
- **Psychology:** Browsing, not buying. Said "interested" casually — like clicking a link. Not ready for qualification.
- **Agent error:** Jumped to qualification without giving value first.
- **Fix:** Lead with a teaser hook. Never ask a question first.

## P2: Info Collector
- **Tagline:** Asks questions, gets answers, stops replying
- **Frequency:** ~13% of leads
- **Behavior:** User asks about price, location, size. Agent answers. User goes silent after receiving info.
- **Psychology:** Researching multiple options. Wanted data points, not a relationship.
- **Agent error:** Gave all info in one go. No staged reveal.
- **Fix:** Stagger information. Each answer should create a new question.

## P3: Border Skeptic
- **Tagline:** "It's in Tamil Nadu? No thanks"
- **Frequency:** ~9% of leads
- **Behavior:** Discovers project is across state border. Raises objection.
- **Psychology:** Emotional objection — mental map excludes the other state.
- **Agent error:** Argued about boundaries instead of reframing.
- **Fix:** "That's exactly why it's more affordable — ₹6,000/sq ft less for being 1km across a line on a map."

## P4: Site-Visit Ghost
- **Tagline:** Said yes to a visit, then vanished
- **Frequency:** ~9% of leads
- **Behavior:** Good engagement, agreed to visit. Then stopped responding when asked to confirm time.
- **Psychology:** Cold feet or busy. Initial excitement faded.
- **Agent error:** Follow-ups after "yes" were generic. No anticipation building.
- **Fix:** Send pre-visit teasers: "Before you visit — the hotel next door is already at floor 3."

## P5: Follow-Up Fatigue
- **Tagline:** "Will get back to you" — never does
- **Frequency:** ~13% of leads
- **Behavior:** Engages, then stalls. Agent sends "checking in" messages, then gives up.
- **Psychology:** Stalling. Not convinced or not the decision-maker.
- **Agent error:** Follow-ups with zero new value.
- **Fix:** Each follow-up = new teaser. Never send "just checking in."

## P6: Handover Drop-Off
- **Tagline:** "Bharat will call you" — nothing happens
- **Frequency:** ~10% of leads
- **Behavior:** Agent escalates to human. Last message is "X will reach out." Momentum dies.
- **Psychology:** Transition dead zone. Prospect feels passed off.
- **Agent error:** No pre-handover teaser. No warm bridge.
- **Fix:** "I've asked Bharat to prepare the best plots. While you wait — Plot 7 has direct golf course view of the 18th hole."

## P7: Budget Objector
- **Tagline:** "₹48 lakhs is too much"
- **Frequency:** ~7% of leads
- **Behavior:** Expresses interest, learns pricing, says too expensive.
- **Psychology:** May be priced out or testing for discounts.
- **Agent error:** Accepted the objection. No reframing.
- **Fix:** "At 20% down, your upfront is ₹9.6L. Here's what similar plots rent for in this corridor..."

## P8: Active Engager
- **Tagline:** Actively conversing, nearly there
- **Frequency:** ~9% of leads (hot status)
- **Behavior:** Multi-turn conversations, asking detailed questions.
- **Psychology:** Highest intent. Close to deciding.
- **Agent error:** Didn't use scarcity or social proof in final push.
- **Fix:** "3 plots booked this weekend by families who visited. Here's why they chose now."

## How to Classify a Lead

1. Read the full chat history
2. Identify the LAST assistant message — what type was it?
3. Count user messages vs assistant messages
4. Match the pattern to the persona
5. The failure mode = what killed the conversation
6. The persona = how to treat this user next time

## How to Use Personas in a Briefing

Embed these so the agent can:
1. **Identify** the persona from early messages
2. **Adapt** the opening teaser based on persona
3. **Recover** when a lead falls into a known failure pattern
