# Investor Deck Structure — Indian Commercial Real Estate

## Source
DRAAS investor presentation created June 2026 for Devasandra Industrial Area land acquisition.
Structure specified and refined by Prakash Singh / Nishant Ranka over multiple review rounds.

## When to use this structure
- User asks for an "information memorandum" or "investor presentation" for a commercial real estate project
- User says "make it more aggressive", "investor presentation", "colourful, design pattern"
- Project involves land acquisition / development in Bangalore/Karnataka

## Required Pre-Work (BEFORE building the deck)

### Jurisdiction - CRITICAL (get this right first)
Do NOT assume jurisdiction. Verify from the user or the allotment document:

| If land is... | Planning Authority | Building Sanction | Applicable FAR Rules |
|---|---|---|---|
| KIADB-allotted (industrial area) | **KIADB** | KIADB Technical Wing | **KIADB Building Byelaws** (GO CI 99 SPQ 2025) |
| BMRDA area | **BMRDA** | BBMP | **BMRDA Master Plan 2031** |
| BDA area | **BDA** | BBMP | **BDA Master Plan 2031 / BBMP Byelaws** |

### KIADB FAR (from GO CI 99 SPQ 2025, Feb 2026)
| Road Width | Base FAR | Premium FAR (50% allotment) | Max FAR |
|---|---|---|---|
| < 12 m | 1.75 | 1.05 | 2.80 |
| 12-18 m | 2.25 | 1.35 | 3.60 |
| 18-24 m | 2.80 | 1.20 | 4.00 |
| **24-30 m** | **3.00** | **1.80** | **4.80** |
| > 30 m | 3.25 | 1.95 | 5.20 |

Other KIADB relaxations: Ground coverage up to 75%, stilt parking exempt from FAR, reduced setbacks for smaller plots.

### Critical data points to collect BEFORE starting
- [ ] Plot area (sqft, sqm, acres, guntas) - from survey sketch or legal document
- [ ] Road width (determines FAR)
- [ ] Jurisdiction (KIADB / BMRDA / BDA / BBMP)
- [ ] Zone classification (Commercial / Industrial / Mixed)
- [ ] Existing structures on site (if any)
- [ ] Metro / transit proximity
- [ ] Market rental rates for comparable properties
- [ ] Recent lease transactions in the vicinity
- [ ] Land guidance value (Kaveri Online / circle rate)
- [ ] Construction cost per sqft (₹1,800-2,000 for shell, ₹2,500-3,000 for Grade A)

### ⚠️ PITFALL: Project data isolation
**Do NOT conflate data from one project with another.** If you just worked on Ranka Amber, clear that context before starting a new project's deck. Verify every number against the new project's documents:
- Plan sanction numbers, dates, references → project-specific
- Unit counts, built-up areas → project-specific  
- Estimated costs → project-specific
- FAR and jurisdiction → verify from scratch, don't carry over from previous project

## 14-Slide Structure

| Slide | Section | Key Content |
|---|---|---|
| **1** | **Title** | Project name, "Commercial Development — Investor Presentation", metro/location tagline, date |
| **2** | **Table of Contents** | Numbered 10-section list in 2-column grid |
| **3** | **Introduction to Land Location** | Overview + 5-6 bullet points (address, extent, jurisdiction, metro, road, current use) + key metrics panel on right |
| **4** | **Land Details** | Tabular: all parameters from survey sketch + valuation callout at bottom |
| **5** | **Survey Sketch & Area Breakdown** | Visual bar chart (components as % of total) + sketch reference panel (access, landmarks) |
| **6** | **Location Advantage** | Metro hero card (large highlight) + 6-point connectivity grid + catchment stats strip |
| **7** | **Key Location Highlights** | 6 cards (3×2 grid): Metro adjacency, Road frontage, IT corridor, Industrial ecosystem, Mixed-use flexibility, Growth corridor |
| **8** | **Infrastructure & Social Accessibility** | Left column: current infra (road, metro, power, water, drainage, telecom). Right column: upcoming projects (Metro Phase 2, elevated corridor, PRR). Social strip at bottom. |
| **9** | **Development Potential** | Left: FAR table (jurisdiction, road width, base/premium/total FAR, ground coverage, stilt parking). Right: image of official FAR table from GO. Bottom: Development scenario table (area, built-up, floors, cost, revenue). |
| **10** | **Comprehensive Market Analysis** | Rental comparables table (7 properties) + Recent lease deals table with dates (6 transactions) + Capital values strip |
| **11** | **Target Audience & Tenant Profile** | 6 tenant segment cards (co-working, medical, retail/F&B, banks, education, IT/ITeS) each with space need, rent bracket, demand indicator |
| **12** | **Premium A-Grade Development Vision** | Vision statement + 4 pillar cards (Retail arcade, Grade A office, Parking/logistics, Building systems/sustainability) |
| **13** | **Financial Overview** | Left: Project Cost breakdown. Right: Revenue Potential (Option A: Sale + Option B: Rental with cap rate valuation). Bottom: 4 returns metrics + thesis statement |
| **14** | **Disclaimer** | Full legal + data sources |

## Revenue Calculation Patterns

### Sale Option
```
Carpet Area = Total Built-up × 0.65 (typical efficiency)
Sale Revenue = Carpet Area × Assumed Rate/sqft
```

### Rental Option  
```
Leasable Area = Carpet × ~0.85 (after common area deduction)
Blended Rate = (Retail sqft × Retail Rate + Office sqft × Office Rate) / Total Leasable
Annual Gross Rent = Leasable Area × Blended Rate × 12
NOI = Annual Gross Rent × 0.90 (90% occupancy assumption)
Valuation @ 8% Cap = NOI / 0.08
Valuation @ 9% Cap = NOI / 0.09  
Valuation @ 10% Cap = NOI / 0.10
```

### Construction Cost
```
Shell + Core: ₹1,800-2,000/sqft
Grade A fit-out: add ₹700-1,000/sqft
Premium FAR: typically 50% of allotment value
Contingency: 10%
```

## Research Techniques for Government Norms
When government websites (.gov.in) are unreachable from the server:
1. **News articles** — Deccan Herald, Times of India, Hindustan Times often cover new GO notifications with specific data
2. **Scribd** — Government orders are frequently uploaded here (search "KIADB NEW REGULATIONS CI 99 SPQ 2025")
3. **LinkedIn posts** — Real estate professionals often summarize new norms
4. **BricknBolt / GeoSquare** — Construction info sites aggregate building byelaws

## Common Pitfalls (from this session)
- **Don't assume BBMP/BMRDA** for industrial area land → verify KIADB jurisdiction
- **Don't carry FAR from previous project to new one** → FAR is jurisdiction + road width specific
- **Don't use 36K sqft built-up for 62K sqft plot** → at FAR 4.8 it's 3,00,000 sqft, a 10x difference
- **Get the road width before calculating FAR** → FAR varies from 2.8 to 5.2 based on road width alone
- **Include BOTH sale and rental options in financials** → investors want to see both exit paths
- **Include reference images from government orders** → adds credibility to the deck
