# Medical Journey Narrative Document

**Trigger:** User wants a comprehensive medical journey document for a patient — designed to be shared with a family member (e.g., "Kanpur Babaji") or kept as a personal record. This is NOT for specialist consultations (see `comprehensive-medical-brief.md` for that) — it's a narrative for family awareness.

## Document Structure

### Personal & Social Details (top section)

Start with who the person is — not just medical data.

```
Name: [Full Name] (also known as [nickname/alias])
Age: [Age] years (born [DOB])
Status: [Single mother / Married / etc.]
Children: [Names and ages]
Residence: Living with [family members, their ages]
Profession: [Job] at [Organization] — [years served]. Currently on [status] since diagnosis.
Email: [email]
```

### Section 1 — Current Condition (Latest Status First)

The user wants the **current state** first, not the history. This is the most important section.

Structure:
```
Diagnosis: [Current confirmed diagnosis] — [key markers]
Current disease: [What it looks like now — size, location, metastases]
Current treatment: [Drug name, dosage, frequency, route]
Treatment centre: [Hospital, City]
Treating oncologist: [Doctor name, credentials]
Patient assistance program: [Name, reference code]

Last [treatment]: [date]
Next scheduled [treatment]: [date]

Prior therapy (completed): [prior treatments, cycles completed]

Latest scan/imaging (date): [RESULT — e.g. STABLE DISEASE / PROGRESSION]
Key biomarkers: [e.g. SUVmax, key values]

Key ongoing concerns:
- [Concern 1]
- [Concern 2]
- [Monitoring plan]
```

### Section 2 — Complete Medical History (Timeline)

Present as a chronological timeline. Year as the header, then bullet points.

```
2016
• First symptom — description

2019 — December
• Diagnostic finding — measurements, locations

2020 — Month
• Specialist review — key decision
• Surgery/procedure — what was done, outcome
• FINAL DIAGNOSIS — confirmed condition

2021 — 2024 (Period description)
• Disease-free / monitoring — frequency, key events

2025 — Month
• Recurrence — discovered how, where
• Biopsy — result
• Treatment start — drug, hospital, doctor

2026 — Month
• Treatment progress — cycles completed
• Imaging — result
• Current status
```

### Photo

Include a link to the person's photo (Aadhar card, passport photo, or standalone):
```
📷 Photo: [Drive link to photo]
(Note: A standalone photo to be added once located)
```

### Delivery

- Create as a **Google Doc** (not PDF, not HTML) so the user can edit and share
- Place in the patient's **medical folder** on Drive
- Name: `YYYYMMDD_Note_for_[Recipient]_[Patient]_Medical_Journey`

## Pitfalls

- **Latest condition first, not history first** — The user explicitly wants Section 1 = current status, Section 2 = timeline. Do NOT write it chronologically with the latest at the end.
- **Photo may need separate sourcing** — The only photo available may be from an Aadhar card. Offer to update with a better standalone photo from Google Photos if the user has one.
- **Age calculation** — Always calculate exact age from DOB at time of document creation, not from memory.
- **Voice-transcribed names** — Confirm spelling of all names (patient, doctors, family members) against written documents.
- **Social context matters** — This document is for family awareness, not clinical use. Include family relationships, profession, years of service — details a family member would care about.
