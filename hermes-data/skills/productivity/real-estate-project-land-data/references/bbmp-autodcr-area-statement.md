# BBMP AutoDCR Sanctioned-Plan — Area Statement Extraction

Worked example: Aug 2026, `PRJ_0987_21-22.pdf` — Ranka North Star Block A
(Allalasandra Sy.No.14/1) BBMP plan sanction. User asked: "Extract the total land
for the project, area of buffer, building line area — generate a complete area statement."

## Document shape (AutoDCR05)

- Generated by "AutoDCR05" (AutoCAD 2013 → pdfplot → iTextSharp), 5 pages, each
  page 7087×2523 pts (~A0 landscape roll).
- **Text layer has ONLY boilerplate** (46 approval conditions, schedule of joinery,
  sign blocks). `pdftotext` finds ZERO area-statement numbers — the area tables are
  AutoCAD-drawn graphics. You MUST render + vision_analyze.
- Page 1 = SITE PLAN + Project Details table; page 2 = BASEMENT FLOOR PLAN + FAR &
  tenement tables; 3 = ground; 4 = typical floors; 5 = section/elevation + joinery.

## Extraction procedure

```bash
pdftoppm -png -r 150 -f 1 -l 5 plan.pdf /tmp/prj/pg      # 14765×5257 px each
# then crop the table bands with PIL:
#   right band  = im.crop((int(w*0.55), 0, w, h))        # Project Details + FAR tables
#   plan zoom   = im.crop((int(w*0.08), int(h*0.18), int(w*0.60), int(h*0.92)))
```

Vision prompts that worked:
- Right band → "Read the Land Use / Zone / Plot Area / Road Width / FAR / Ground
  Coverage / Height / Setbacks / Basement Coverage / Buffer Area / Premium FAR /
  Total FAR table VERBATIM with units."
- Right band lower → "Read the FAR & Tenement Details table (floor, area sq.m,
  permissible, proposed, deductions) and parking table."
- The plan drawing itself: use `pdftotext -bbox` for labels; whole-page OCR of the
  site-plan drawing garbles (vector hatch). For buffer/building-line zones on the
  drawing, crop tight windows and ask for dimension labels only.

## Buffer / building line — where they actually live

- The **1.00 M "buffer"** in the Project Details table is a compliance figure, NOT
  the lake-buffer area. For sites near a lake, the drawing carries a separate
  drawn label **"30M LAKE BUFFER LINE"** (page 2 plan; building is inscribed inside
  it). The lake-buffer AREA requires plan geometry (or the PreDCR area statement,
  e.g. North Star net 44,921 sq.ft after 24M-buffer + road deduction on the
  53,089 sq.ft amalgamated parcel).
- "Building line" = setbacks (5.00 M all sides in this sanction). BBMP AutoDCR
  doesn't print a separate "building-line area" row — it is implied by setbacks + FAR.

## Pitfalls

- Do not grep the text layer for area numbers — they are not there.
- The left plan drawing OCRs poorly at whole-page scale; crop sections.
- Whole-doc `pdfinfo` shows 5 pages, but conditions repeat on every page — only the
  table bands on pages 1–2 matter.
- 30M Lake Buffer Line is a drawn vector label — confirm with a targeted vision crop
  (it appeared on both west and north/south edges in this plan), don't OCR the whole page.
