# Worked Example: Serenity Hillview Plot Comparison

## Source Sheets
- **OLD:** Final Plot Distribution Sheet (client-shared measurements)
- **NEW:** BK - Plot Update (post-revision with road merger)
- Both in same spreadsheet: `Anjali - Serenity Hillview Plotal Inventory Data`

## Key Change
Plots 1, 2, 4, 5 were merged into a single Plot 1, with road area added.

### Merged Plot Comparison

| Parameter | Old (1+2+4+5) | New (Plot 1 + road) | Change |
|-----------|---------------|--------------------|--------|
| Registrable Area | 22,396.07 sqft | **24,064.67 sqft** | **+1,668.60** |
| % of Plot Area | 9.94% | **11.46%** | **+1.52%** |
| UDS sqft | 6,798.45 | **7,951.98** | **+1,153.53** |
| UDS Loading % | 30.36% | **33.04%** | **+2.68%** |
| Total Area | 29,194.52 | **32,016.65** | **+2,822.13** |

### UDS Increase: Three Components

1. **Road area at old rate:** 1,668.60 × 30.36% = **506.59** sqft
2. **Higher loading on existing:** 22,396.07 × 2.68% = **600.21** sqft
3. **Higher loading on road:** 1,668.60 × 2.68% = **44.72** sqft
4. **Total:** 506.59 + 600.21 + 44.72 = **1,151.52** (≈ 1,153.53, rounding)

### Why Loading % Rose (30.36% → 33.04%)
Road/common area merged → common area pool reduces → land redistributes → each plot's UDS share increases.
