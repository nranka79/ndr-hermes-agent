📡 OAuth flow architecture (reference)
# How the per-user OAuth token works:

1. User messages @NDRHermes_bot on Telegram
2. Gateway sets env: HERMES_SESSION_USER_ID = <telegram_id>
3. Agent calls: tools.gws_auth.get_auth_url(telegram_id)
   → Generates Google OAuth URL with state=telegram_id
   → Redirect URI: https://transcribe.ahfl.in/gws/auth/callback
4. User clicks link → Google login → consent screen → redirect back
5. Nginx proxies /gws/auth/callback → hermes API server (port 8642)
6. Hermes: exchange_and_store(telegram_id, code)
   → stores token at /data/hermes/users/{telegram_id}/gws_token.json
7. Hermes sends Telegram message to user confirming success

# OAuth client (shared across all users):
HERMES_OAUTH_CLIENT_ID = 353166898892-1i1vl4p3uakjahefg11jpvrhnclei5l3...
Redirect URI: https://transcribe.ahfl.in/gws/auth/callback

# Token storage path (inside container = on host at hermes-data/):
/data/hermes/users/{telegram_id}/gws_token.json
